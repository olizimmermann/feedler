# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems. Report them privately through GitHub's [private vulnerability reporting](https://github.com/olizimmermann/feedler/security/advisories/new) instead. Include what's affected, how to reproduce it, and the impact you expect.

You'll get a reply within a week. Fixes go into the `main` branch, and the advisory is published once a fix is available.

## Supported versions

Only the latest `main` is supported.

## Deployment notes

Feedler is meant to be self-hosted. Please read the *Security notes* section of the [README](README.md#security-notes) before exposing it to the internet or to users you don't trust.
